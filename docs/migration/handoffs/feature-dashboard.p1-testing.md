**Structural note for the planner.** All 9 Fragment test classes that use a ViewModel replace it with a relaxed `@BindValue` mock and stub
`LiveData.observe(...)` to push one value synchronously. After the refactor these tests cannot run unchanged. A relaxed mock of a
`StateFlow`
does not emit, so a "not displayed" assertion on a view that the XML already hides would still pass even though nothing rendered. Treat
the ViewModel-level tests and the new P0 tests below as the regression net that carries through the refactor, and re-point every Fragment
test at the new state stream before you rely on it.

## 10. Risk summary

| #    | Risk                                                                                                                                                                                                                                                                                                                                                                              | Screens                                          | Mitigating tests                                       |
|------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------|--------------------------------------------------------|
| R-1  | **Pre-logout sync chain breaks.** Images must start after events complete, and the logout command must be exactly `OneTime.Logout.start()` after the 3 s debounce. The image auto-start is untested and the logout command assertions accept any command. A broken chain strands the user on the logout screen or logs out with unsynced images.                                  | SyncInfo (logout host), LogoutSync               | S-1, S-2, S-3, LV-1, AB-1                              |
